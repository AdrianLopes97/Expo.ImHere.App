# ImHere

ImHere é um aplicativo mobile desenvolvido em React Native para gerenciar a presença de participantes em eventos.

## Funcionalidades

- Adicionar participantes
- Remover participantes
- Listar participantes presentes

## Tecnologias Utilizadas

- React Native
- Expo
- JavaScript

## Como Executar o Projeto

1. Clone o repositório:
    ```sh
    git clone https://github.com/seu-usuario/imhere.git
    ```
2. Navegue até o diretório do projeto:
    ```sh
    cd imhere
    ```
3. Instale as dependências:
    ```sh
    npm install
    ```
4. Execute o projeto:
    ```sh
    expo start
    ```
